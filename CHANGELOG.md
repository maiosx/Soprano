# Changelog

## [1.0.1] - 2026-08-25

### Fixed

- Character names along the bottom of the overlay span the full width and wrap, so none are clipped.

## [1.0.0] - 2026-08-25

### Added

- Fullscreen Omarchy overlay of quotes from The Sopranos.
- Click, Space, Enter, or → for another quote. Escape dismisses.
- Character filter along the bottom of the overlay.
- Bar widget uses an **S** (not a `$`).
- IPC: `omarchy-shell soprano toggle|open|close|status` and `omarchy-shell shell toggle soprano.quotes`.
